# Contributing

Use the README's demo and test commands, and a fresh output directory. A focused
contribution includes the release/commit, OS/runtime, exact command, expected
reason/exit and smallest **synthetic** reproduction. Do not upload a real database,
row data, account details, credentials or private source. Preserve failed evidence.

Add meaningful failure-boundary tests for a behavioral change. Do not weaken
the fresh-target, standalone-artifact, trusted-profile, worker-output or cleanup
guards to make a fixture pass. Source/CI/signatures are separate from a production,
customer, freshness, performance or skill claim. Do not rewrite historical tags,
checksums or release assets. License/publication decisions remain owner decisions.
